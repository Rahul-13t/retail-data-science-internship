Week 3 - Demand Forecasting and Predictive Modeling

This week focuses on analyzing historical retail sales data and developing a predictive model for demand forecasting.

Work Performed
Prepared historical retail sales data for forecasting
Aggregated transaction data into monthly sales
Created time-based features
Divided the data into training and testing sets
Applied Multiple Linear Regression
Evaluated the model using MAE and RMSE
Compared actual and predicted sales
Generated a three-month future sales forecast
Created visualizations for sales trends and predictions
Tools Used

Python, Pandas, NumPy, Matplotlib, and Scikit-learn.
