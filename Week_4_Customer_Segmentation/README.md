# Week 4 - Customer Segmentation and Clustering

This week focuses on analyzing customer purchasing behavior and creating customer segments using RFM analysis and K-Means clustering.

## Work Performed

- Prepared retail transaction data for customer analysis
- Removed duplicate and invalid transactions
- Excluded records with missing CustomerID for segmentation
- Calculated Recency, Frequency, and Monetary values
- Standardized RFM features using StandardScaler
- Used the Elbow Method to evaluate different cluster sizes
- Used Silhouette Score to evaluate clustering quality
- Applied K-Means clustering
- Created four customer segments
- Visualized customer clusters
- Analyzed characteristics of different customer groups
- Suggested retail strategies for different customer segments
